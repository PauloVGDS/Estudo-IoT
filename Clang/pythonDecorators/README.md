# Programação Orientada a Aspectos(AOP)
- POO utilizada junto da AOP oferece aumento na coerência.
- Exemplo de funções transversais usando decoradores:
- Decorador `@loggin`:
    - Adiciona uma verificação de autenticação sem alterar o código dessas funções diretamente.
- Decorador `@operacoes`:
    - Adiciona lógica de log no extrato e uma mensagem sem alterar o código dessas funções.
